# 面向普通用户的术语与交互规范

状态：已确认，待后续开发任务实施。

本文面向项目开发者和代码代理，用于统一插件公开发布后的产品术语、统计口径、功能边界与关键交互。修改界面文案、首次引导、README、状态提示、分类流程或视频卡片前，应先阅读本文。

## 1. 基本原则

- 主界面优先使用普通用户可以直接理解的中文，不直接暴露 `keyword`、`LLM`、job、cache 等内部术语。
- 用户看到的是“分类阶段”和“下一步可以做什么”，内部代码仍可继续使用 `keyword`、`llm`、`manual` 等稳定字段，避免无必要的数据迁移。
- “分类目录”和“视频分类”是两个不同对象，所有按钮、提示和更新说明都必须明确区分。
- 手动确认的视频分类具有最高优先级，任何自动分类、导入、重置或修复流程都不得覆盖。
- 后台同步和详情补充属于运行状态，不属于分类统计。

## 2. 分类阶段与分类方式

界面对分类结果采用“两种阶段、三种方式”的表达。


| 内部来源  | 用户名称 | 分类阶段 | 用户含义                                                 |
| --------- | -------- | -------- | -------------------------------------------------------- |
| `keyword` | 初步分类 | 粗分类   | 插件根据标题、分区等信息快速自动判断，可能需要进一步确认 |
| `llm`     | AI 分类  | 细分类   | AI 阅读视频信息后进行更准确的分类                        |
| `manual`  | 手动确认 | 细分类   | 用户亲自调整并保存，自动流程不得覆盖                     |

统一优先级：**手动确认 ＞ AI 分类 ＞ 初步分类**。

视频卡片来源徽章分别采用初步分类蓝色、AI 分类紫色、手动确认绿色；结果不确定采用黄色、建议重新分类采用橙色、分类异常采用淡红色。内容分类徽章复用已有分类色板，使用淡彩底和同色系深色文字，不显示边框。删除操作采用 15px 的 Lucide 垃圾桶轮廓，线宽为 1.5，按钮点击区域保持不变。

视频卡片来源徽章使用：

- 初步分类
- AI 分类
- 手动确认

首次引导或帮助说明使用：

- **初步分类**：插件会先自动整理，速度快，但可能不够准确。
- **AI 分类**：使用 AI 进一步判断视频内容。
- **手动确认**：你亲自确认的分类具有最高优先级，不会被自动修改。

## 3. 特殊分类与筛选

### 待精细分类

左侧原“未分类 / 待更新”统一改为 **待精细分类**。它是工作状态筛选，不是分类目录中的一个分类。

应纳入该筛选的情况：

- 只有初步分类；
- 没有有效分类；
- 分类结果过旧；
- 分类结果不确定或低置信度。

用户可以选择 AI 分类或手动调整，因此不得写成“待 LLM”或“待手动”。

### 暂未归类

分类目录中原“其他 / 待整理”改为 **其他 / 暂未归类**。它表示现有信息不足，暂时无法确定更合适的目录位置，是正常的兜底分类。

内部 id 可继续保持 `other.todo`，无需仅为文案改名迁移历史数据。

侧栏顶部固定显示“全部视频”和“待精细分类”，下方排列内容分类，不显示“按处理状态”和“按内容分类”标题。两类筛选可以重叠：初步归入科技的视频仍待精细分类；手动确认放在暂未归类的视频不再待精细分类。对默认 `other.todo` 中残留的“待整理”只更新名称，不修改视频归属；用户自定义名称保留。

侧栏分类采用参考图中的无边框分组文字列表：一级分类文字较深，组间距为 6px；子分类文字为灰色并缩进，行间留白为 2px，子分类最小行高为 28px、一级分类为 32px；数量在分类行右侧对齐，与名称至少间隔 6px，整体紧凑。左侧栏默认占宽 240px，左侧栏采用 24px 圆角与 8px 外边距。未选中项背景透明，数量不使用胶囊背景；移除分类拖动排序、拖动手柄和相关提示。手动分类选择器继续使用中性浅底、细边框及蓝灰选中态。分类本身及其筛选功能保留。

侧栏鼠标悬停或键盘可见焦点时渐入光流与光点；鼠标按下留下的焦点不算键盘预览，按住移出、释放在分类外、取消指针操作或离开窗口后清除悬停预览，真实选中项的光效仍保留；仅实际点击的分类显示选中玻璃与圆点，同一时刻仅有一块共享磨砂玻璃，玻璃在选中位置之间用 560ms 秒的慢速波相互干涉，让纹理持续扭曲、生成与消散，连续风场为主体，运动中偶尔浮现低对比度、不等距的细微条纹，条纹随波场生成和消散，不呈固定平行带；色光边缘与两端自然渐隐，不使用固定带子、团块或外框；整体面积略扩大、左侧更宽、波场起伏幅度增加约 20%，速度保持缓慢；在选中项中心扣除波的位移，保持视觉中心稳定并让两侧自然交替偏转，渐变颜色随波场缓慢交融，叠加始终可见的中心底光，左上与右下同时溢出，选中项保持在色彩中心；0.9 至 1.6px 的粒子采用分类同色亮点与细小彩色光晕，不使用纯白亮芯，以 4.8 至 6.4 秒为周期向右流动，亮起后逐渐变暗缩小，80% 的粒子在行程后段提前湮灭，不在途中重新闪亮，色光始终位于玻璃下方；粒子按分类 ID 稳定随机分配到玻璃前后两层，约 40% 位于玻璃上方、其余被玻璃柔化，分类文字和数量位于所有视觉效果上方，保持清晰可读；选中卡片使用白色与分类浅色混合的磨砂层和 14px 背景模糊；色光与后景粒子位于玻璃底层，卡片范围内的条纹被玻璃柔化，溢出部分保留纹理，不显示硬描边，玻璃保留微弱边缘光泽与柔和阴影，不使用片状火焰。每个分类按 ID 稳定分配 24 组和谐渐变与小幅色相变化，包含薄荷天蓝、冰蓝薰衣草、丁香玫瑰、珊瑚蜜桃、香槟金、柑橘鼠尾草、翡翠海水、暮蓝紫粉等相邻色与柔和多色过渡；分类 ID 的分配充分打散，避免相似 ID 聚集到同色，刷新、改名与列表排序不改变配色；光流使用该渐变的三段颜色，粒子由渐变起点经过中段向终点逐渐变色，粒子光晕与亮点同色，静态回退也保留三段渐变；所有色相统一渲染明度、波场和玻璃参数，重绘时刷新配色缓存；顶部“全部视频”和“待精细分类”选中后也显示同样的效果，分别采用蓝色与金橙色。一级分类或有子分类的类别使用更饱满的色云与 28 个粒子，叶子小分类使用较轻的色云与 16 个粒子；选择大分类仍筛选其所有子分类的视频，但子分类不同时显示选中效果。减少动态效果时绘制静态波场；WebGL 不可用时保留静态渐变，减少透明效果时使用实色卡片，强制颜色模式下使用系统选中色。操作反馈采用带底色的紧凑圆角条，在右上角、顶栏下方自动弹出并自动消失：进行中为蓝色，成功为绿色，失败为红色；长消息在条内滚动，完整记录仍保存在操作日志。操作反馈、分类目录生成、API 测试和首次引导的运行通知复用分类选中项的无边框通透磨砂层、动态波场与前后景粒子，方向镜像为右宽左窄、从右向左流动，通知文字始终位于最上层；进行中为蓝色、成功为绿色、失败为红色，状态切换立即刷新波场配色。通知玻璃与同步按钮共用轻透材质、2px 背景模糊及微弱高光，本身按进行中蓝色、成功绿色、失败红色染色，保持原有流光波场、前后景粒子及动画参数不变。顶部工具栏分为查找视频、更新与管理、B站导航三组。所有控件保持单行，功能组之间使用带静态光泽的竖线分隔。搜索框在常见桌面宽度下为 260 至 320px，窄窗口为 240px；同步、批量管理与设置整组靠右，与 B站导航相邻。竖线采用等宽 2px、高 22px 的直线，仅使用横向白色与浅冰蓝高光，不含深色中段、纵向收窄或端点光斑。三个 B站入口的 SVG 与按钮均按几何中心对齐。搜索输入框聚焦时不显示蓝色外圈，保持中性磨砂底色，内部输入不显示独立边框或默认焦点背景。所有操作图标统一使用 Lucide，三个 B站导航图标保留原样。搜索框宽度随窗口调整；窄窗口中同步与批量管理缩为带完整提示的图标按钮，空间仍不足时整条工具栏横向滚动，不换行。全部控件共用静态 Liquid Glass 材质，采用通透底色、轻微色散和克制的边缘高光，不使用持续动画、动态 SVG 折射或彩色大面积投影。同步保留淡绿色玻璃及深绿色图标；主页、稍后再看、动态的粉、蓝、黄色仅用于图标轮廓，按钮底色保持中性。乱序与设置为低权重图标按钮，提供完整提示和可访问名称。控件高度为 36px，圆角为 12px，顶栏圆角为 24px；下拉列表为乳白玻璃，保留原生键盘选择、清晰选中态和焦点提示。

顶部搜索筛选栏采用半透明毛玻璃材质与 24px 圆角，去掉底部分隔线；中间滚动区上下各留 8px，与左侧栏顶部对齐，滚动时能透出模糊的视频内容。中间滚动条宽 6px，轨道上下各留 12px，滑块保持圆角与透明轨道；视频区内边距为上下 16px、左右 14px。左侧产品标题与副标题固定在顶部，“全部视频”和“待精细分类”固定在侧栏顶部；其中标题与副标题使用不透明白底，去掉可见模糊效果，顶部两个筛选卡片所在区域保留毛玻璃。系统要求减少透明效果或启用强制颜色时使用不透明背景，优先保证阅读。

### 分类异常

左侧内容分类列表首尾相连，向上或向下都可连续循环滚动，隐藏滚动条且不保留滚动条占位；产品标题、“全部视频”和“待精细分类”保持固定，不参与循环。循环仅改变目录的显示方式，不改变分类顺序、视频归属或手动确认结果。分类筛选和页面重绘后的滚动位置保留，分类拖动排序已移除。

“未分类”不作为常驻入口或统计项。真正没有任何有效分类的情况统一称为 **分类异常**，只在数量大于 0 或确实需要用户处理时显示。

## 4. 浏览布局与操作反馈

主界面仅保留左侧分类和中间视频区，移除右侧常驻管理栏及“全部视频、待精细分类、AI 已分类、手动确认”四个统计数字。分类阶段的内部统计逻辑继续用于筛选和自动分类，不在右侧展示。

左侧“全部视频”和“待精细分类”与其他一级分类使用相同的 32px 行高和文字、数量大小，保持固定入口并显示对应数量。视频区以当前分类名称作为醒目标题，数量为辅助文字。桌面宽度（大于 1000px）采用五列视频卡片，窄窗口降为三列、两列或一列。

顶部“设置”打开固定尺寸的磨砂弹窗，常驻导航依次显示“AI 批量视频分类”“编辑分类目录”“API 与自动化”，并各用一句话说明用途。标题、导航和子页切换入口固定，只有当前内容区滚动；切换不会改变弹窗长度或屏幕位置，保留各页滚动位置和未保存草稿。手动分类使用独立磨砂弹窗：点击视频卡片文字区打开，点击封面仍直接打开普通视频页。批量管理入口位于顶栏，批量操作仍在顶部固定区进行。

操作反馈复用现有粒子波场磨砂面板，在右上角、顶栏下方 12px 自动弹出；根据顶栏高度、批量区展开及窗口尺寸调整位置，避免遮挡操作按钮。普通提示 5 秒后消失，失败提示 8 秒后消失；新消息重新计时，完整记录保存在本机操作日志。弹窗支持关闭按钮和 Escape，键盘焦点限制在弹窗内，关闭后回到入口。

## 5. 分类目录与视频分类的固定边界

### 分类目录

分类目录表示“有哪些分类，以及它们之间的层级关系”。统一使用以下表达：

- 编辑分类目录
- 让 AI 生成分类目录
- 导入并替换分类目录
- 恢复默认分类目录

避免使用含义不明确的“更新分类列表”。相关说明应明确写出：

> 分类目录决定可以使用哪些分类；生成目录本身不是在给每个视频分类。

“编辑分类目录”分为“手动编辑”和“让 AI 生成目录”两个子页。手动编辑显示草稿数量、按需展开的添加类别表单和目录列表。表头位于分类行滚动区外，随页面框架固定，不参与列表滚动或在列表中间悬浮。表头标明层级、分类名称、上级分类；层级使用一级、二级、三级等文字标签，名称适当缩进，一级分类加重。目录、手动选择和批量下拉统一使用层级文字，不显示 L 型树枝符号。上级为“无上级（一级分类）”时作为根分类；修改上级后立即刷新分级并排除循环关系。保存和放弃修改固定在底部，不随列表滚走。新增、改名、移动和删除仍需点击“确定保存”才生效；输入名称时只更新草稿状态，完成输入后更新父级选项。AI 生成与替换目录只在独立子页显示。

### 视频分类

视频分类表示“把具体视频放入分类目录中的位置”。统一使用以下表达：

- AI 批量视频分类
- 手动调整视频分类
- 重新分类这些视频
- 批量调整视频分类

### 已确认的功能名称


| 当前名称           | 确认采用的名称                      |
| ------------------ | ----------------------------------- |
| 分类管理           | **编辑分类目录**                    |
| 自动 LLM 分类      | **AI (API) 批量视频分类**           |
| 手动 LLM 导入/导出 | **AI (手动导入/导出) 批量视频分类** |
| 手动修正           | **手动调整视频分类**                |

功能名称中的括号和 `API` 按以上文本保留，以便明确区分插件自动调用 API 与用户手动复制、导入结果两条流程。

“AI 批量视频分类”分为“使用 API 自动分类”和“手动复制 Prompt”两个子页，同一时刻只显示所选方式。API 页提供处理数量、重新处理已有 AI 分类和启动操作；手动页依次提示生成并复制 Prompt、交给 AI、粘贴并导入视频分类结果。

“API 与自动化”分为“API 设置”“自动分类”“操作日志”三个子页。每页显示直接说明，无嵌套折叠标题；自动分类的数量阈值只在数量模式下显示；各表单区块间隔 16px，标签与控件间隔 8px。API 配置和输入草稿切换时保留，保存后才生效。

输入框与选择器沿用顶部乳白到冰蓝的无描边磨砂底色，普通操作使用浅蓝灰按钮，主要操作使用蓝灰渐变，危险操作保留淡红色。控件圆角为 12px，目录行保持紧凑。桌面表单使用两列，窄屏改为一列；目录表格的层级列保持完整可读，不显示横向滚动条。键盘焦点保持可见。

**视频分类服务**可选择 OpenAI-compatible 或 Jev（TypeSafe），两者密钥独立保存。Jev 从现有目录中为每个视频选择一个类别，不生成分类目录；分类目录生成始终使用 OpenAI-compatible 配置。Jev 结果仍显示“AI 分类”，结果不确定时留在“待精细分类”。

设置中的选择器名称为“视频分类使用的 API”，只显示所选服务的配置和简短介绍。切换保留两套配置，保存后生效；操作按钮标明“测试 Jev / OpenAI-compatible”和“保存并使用 Jev / OpenAI-compatible”。OpenAI-compatible 的温度和 JSON 输出选项收起在“高级选项”中。

**自动 API 视频分类** 作为“API 与自动化”中的独立子页，可选择关闭、每天、每周，或在“待精细分类”达到用户指定数量时自动触发。自动流程仍不得覆盖手动确认。

**操作日志** 作为“API 与自动化”中的独立子页，自动保存最近 200 条页面操作反馈，显示时间、状态和内容，最新记录在上方。记录仅保存在本机，刷新后保留；连续相同反馈不重复记录。日志不保存已配置的 API 密钥，存储失败时明确提示当前记录未持久化。

## 6. 视频卡片操作

视频区采用参考图中的浅灰背景（`#EEEEEE`）与白色圆角卡片，通过卡片间距和文字区留白区分内容。视频卡片不显示外边框或选中描边；选中通过柔和灰蓝渐变底色区分，批量选中另有勾选标记。封面铺满卡片顶部和左右边缘，顶部两角与卡片的 16px 圆角对齐，封面底部不设圆角；文字与操作区域保留内边距。底部操作采用浅灰底色、无边框按钮。键盘操作入口保留清晰的焦点提示。

顶部“乱序”按钮将当前筛选下的视频随机排列，通过位置过渡呈现重排，不改变选择、分类或 B站服务端顺序。至少两个视频时可用，每次点击都会改变当前顺序；本次页面内保持随机顺序，详情刷新不重新洗牌，新同步的视频排在现有随机序列之后。排序选择器显示“随机排序”，选择其他排序即可退出；刷新页面恢复原来保存的常规排序。系统开启“减少动态效果”时直接切换位置。

进入页面默认不选择视频；同步和详情刷新也不得自动选择第一条。仅保留用户主动选择且仍在稍后再看中的视频；所选视频被移除时清空选择，不自动切换到下一条。同步新增或重新加入的视频使用淡入上移动画，已有卡片平滑让位；详情刷新沿用当前动画进度，不从头重复播放。

顶部按钮取色以用户提供的参考图片为准：主页粉色 `#FF6699`，稍后再看蓝色 `#00AEEC`；同步配套绿色 `#39BD88`，动态配套黄色 `#FFCC55`，同步使用淡绿色玻璃与深绿色图标，三个站外入口仅在图标轮廓中保留对应色相（黄色适度加深以保证对比度），底色与阴影保持中性。

视频卡片采用以下交互：

- 删除“普通打开”文字按钮；
- 点击视频封面，直接打开普通 B站视频页面；
- “稍后播放”改名为 **稍后合集中打开**，用于进入 B站稍后再看播放上下文；
- “移出稍后”改为单独的删除图标按钮；
- 删除图标必须具有明确的 `title` 和 `aria-label`，推荐使用“移出稍后再看”；
- 点击删除图标后立即从当前列表隐藏，再由后台向 B站确认；确认失败时必须恢复视频并明确提示原因；
- 视频标题是否同时打开普通视频页可在实施时根据可访问性决定，但不得与卡片选择、文字选择或手动分类操作冲突。

实现时继续遵守已有交互约束：不得引入滚动跳动、文本选择丢失、输入法异常或批量选择失效。

删除后其余视频卡片平滑补位，失败恢复时也使用位置过渡；系统开启“减少动态效果”时直接更新位置。手动调整视频分类与批量管理共用紧凑的多列复选分类控件，分类项通常为 32px 高，显示层级与名称，完整分类路径在悬停提示中显示；一级分类不独占整行，选中底色与复选框清楚呈现归属，不单独限制分类列表高度。手动调整点击“保存为手动确认”后才保存；底部三个操作按钮放在滚动内容区外的独立 16px 圆角区域，始终可见。批量管理可同时勾选多个分类，一次追加到所选视频并保留原有分类；面板使用中性半透明底色，按钮与其他面板统一，保留键盘焦点。

## 10. 圆角层级

参考 Apple 的同心圆角原则（https://developer.apple.com/documentation/swiftui/edge/corner/style/concentric），按容器、卡片、控件和内部小元素分配圆角，而不是全部使用同一数值。以下数值为本页面的设计选择：左侧栏、设置弹窗、中间滚动区与磨砂顶栏使用 24px；视频卡片与通知消息使用 16px；输入框、下拉框、普通按钮与分类玻璃使用 12px；视频卡片内部按钮和小徽章使用 8px。顶栏内边距为 12px，与内部 12px 控件圆角协调；展开下拉列表使用 18px，配合 6px 内边距和 12px 选项圆角。视频封面贴边，因此顶部圆角与卡片共用 16px，底部保持直角。分类和通知的玻璃层继承容器圆角；粒子、状态小圆点和滚动条仍保持圆形或全圆角。所有尺度由 CSS 变量统一维护。

分类、视频状态筛选与搜索切换时，离开的可见卡片在 150ms 内淡出；新出现或原本离得很远、位于屏幕外的卡片用 400ms 小幅上移淡入，逐张错开 22ms；附近共有卡片平滑补位。完全无交集的分类也呈现完整退出与入场动画，空结果也淡入，常规排序复用乱序的位置过渡。搜索与分类同时生效；存在搜索词时搜索框保持原有中性底色，不显示渐变或高亮外圈；当前分类标题旁显示中性灰底的“关键词筛选中”，数量旁提示“仅显示搜索匹配”。输入法组词期间不更新结果，结束输入后以 100ms 合并输入更新。减少动态效果时直接显示结果。
