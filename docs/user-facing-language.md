# 面向普通用户的术语与交互规范

状态：已确认，待后续开发任务实施。

本文面向项目开发者和代码代理，用于统一插件公开发布后的产品术语、统计口径、功能边界与关键交互。修改界面文案、首次引导、README、状态提示、分类流程或视频卡片前，应先阅读本文。

## 1. 基本原则

- 主界面优先使用普通用户可以直接理解的中文，不直接暴露 `keyword`、`LLM`、job、cache 等内部术语。
- 用户看到的是“分类阶段”和“下一步可以做什么”，内部代码仍可继续使用 `keyword`、`llm`、`manual` 等稳定字段，避免无必要的数据迁移。
- “分类目录”和“视频分类”是两个不同对象，所有按钮、提示和更新说明都必须明确区分。
- 手动确认的视频分类具有最高优先级，任何自动分类、导入、重置或修复流程都不得覆盖。
- 后台同步和详情补充属于运行状态，不属于分类统计。

## 2. 分类阶段与分类方式

界面对分类结果采用“两种阶段、三种方式”的表达。


| 内部来源  | 用户名称 | 分类阶段 | 用户含义                                                 |
| --------- | -------- | -------- | -------------------------------------------------------- |
| `keyword` | 初步分类 | 粗分类   | 插件根据标题、分区等信息快速自动判断，可能需要进一步确认 |
| `llm`     | AI 分类  | 细分类   | AI 阅读视频信息后进行更准确的分类                        |
| `manual`  | 手动确认 | 细分类   | 用户亲自调整并保存，自动流程不得覆盖                     |

统一优先级：**手动确认 ＞ AI 分类 ＞ 初步分类**。

视频卡片来源徽章分别采用初步分类蓝色、AI 分类紫色、手动确认绿色；结果不确定采用黄色、建议重新分类采用橙色、分类异常采用淡红色。内容分类徽章复用已有分类色板，使用淡彩底和同色系深色文字，不显示边框。删除操作采用 15px 的 Lucide 垃圾桶轮廓，线宽为 1.5，按钮点击区域保持不变。

视频卡片来源徽章使用：

- 初步分类
- AI 分类
- 手动确认

首次引导或帮助说明使用：

- **初步分类**：插件会先自动整理，速度快，但可能不够准确。
- **AI 分类**：使用 AI 进一步判断视频内容。
- **手动确认**：你亲自确认的分类具有最高优先级，不会被自动修改。

## 3. 特殊分类与筛选

### 待精细分类

左侧原“未分类 / 待更新”统一改为 **待精细分类**。它是工作状态筛选，不是分类目录中的一个分类。

应纳入该筛选的情况：

- 只有初步分类；
- 没有有效分类；
- 分类结果过旧；
- 分类结果不确定或低置信度。

用户可以选择 AI 分类或手动调整，因此不得写成“待 LLM”或“待手动”。

### 暂未归类

分类目录中原“其他 / 待整理”改为 **其他 / 暂未归类**。它表示现有信息不足，暂时无法确定更合适的目录位置，是正常的兜底分类。

内部 id 可继续保持 `other.todo`，无需仅为文案改名迁移历史数据。

侧栏顶部固定显示“全部视频”和“待精细分类”，下方排列内容分类，不显示“按处理状态”和“按内容分类”标题。两类筛选可以重叠：初步归入科技的视频仍待精细分类；手动确认放在暂未归类的视频不再待精细分类。对默认 `other.todo` 中残留的“待整理”只更新名称，不修改视频归属；用户自定义名称保留。

侧栏分类采用参考图中的无边框分组文字列表：一级分类文字较深，组间距为 6px；子分类文字为灰色并缩进，行间留白为 2px，子分类最小行高为 28px、一级分类为 32px；数量在分类行右侧对齐，与名称至少间隔 6px，整体紧凑。左侧栏默认占宽 240px，左侧栏采用 24px 圆角与 8px 外边距。未选中项背景透明，数量不使用胶囊背景；移除分类拖动排序、拖动手柄和相关提示。手动分类选择器继续使用中性浅底、细边框及蓝灰选中态。分类本身及其筛选功能保留。

### 分类异常

左侧内容分类列表首尾相连，向上或向下都可连续循环滚动，隐藏滚动条且不保留滚动条占位；产品标题、“全部视频”和“待精细分类”保持固定，不参与循环。循环仅改变目录的显示方式，不改变分类顺序、视频归属或手动确认结果。分类筛选和页面重绘后的滚动位置保留，分类拖动排序已移除。

“未分类”不作为常驻入口或统计项。真正没有任何有效分类的情况统一称为 **分类异常**，只在数量大于 0 或确实需要用户处理时显示。

## 4. 浏览布局与操作反馈

装饰光流和粒子仅在用户操作后的 5 秒内运动，页面静置后保持当前画面；切到其他标签或窗口立即暂停，返回并操作时恢复。光流最多每秒绘制 15 次，实际未显示的分类行不绘制。该限制适用于分类、顶栏筛选及操作反馈中的装饰效果，卡片移动与实际任务进度保持原有行为。

封面继续预加载附近几屏；视频区停止滚动 500ms 后释放仍在 3600px 以外的图片来源，返回预加载范围后从浏览器本地恢复已保存的图片文件。卡片节点、视频信息、分类归属和滚动位置保留。

主界面仅保留左侧分类和中间视频区，移除右侧常驻管理栏及“全部视频、待精细分类、AI 已分类、手动确认”四个统计数字。分类阶段的内部统计逻辑继续用于筛选和自动分类，不在右侧展示。

左侧“全部视频”和“待精细分类”与其他一级分类使用相同的 32px 行高和文字、数量大小，保持固定入口并显示对应数量。视频区以当前分类名称作为醒目标题，数量为辅助文字。视频网格按视频区实际可用宽度切换列数；紧凑窗口按每张卡片至少 190px、列间距 12px 计算一至五列，视频区达到 1200px 后显示六列，最多六列，避免卡片过窄。封面始终保持 16:9；标题完整换行显示，不限制行数、不用省略号；同一排卡片的标题区由该排最长标题决定高度，各排独立计算，窗口宽度、筛选与排序变化后自动重新对齐。同一排卡片的 UP 主、发布时间和分类标签起点对齐。

顶部“设置”打开宽幅固定尺寸的磨砂弹窗，顶部紧凑导航依次显示“AI 批量视频分类”“编辑分类目录”“AI 服务”“浏览设置”“小工具”“操作日志”。标题、导航和子页切换入口固定，只有当前内容区滚动；切换不会改变弹窗长度或屏幕位置，保留各页滚动位置和未保存草稿。手动分类使用独立磨砂弹窗：点击视频卡片文字区打开，点击封面仍直接打开普通视频页。手动分类弹窗在桌面窗口中采用左侧视频信息（宽度最多 480px）、右侧三列分类卡片，宽度随窗口扩大至 1360px，普通分类数量下尽量完整展示，内容超出窗口时才滚动；窄窗口恢复上下排布。放大封面和标题，并直接展示本地已保存的 UP 主、分区、时长、播放量、观看进度、发布时间、加入稍后再看时间、视频编号、标签、完整简介及分 P 标题；已有分类及其依据一并展示。缺失信息显示“暂无信息”，标签和简介分别标注缺失；不把未获取的数据显示为零。批量管理入口位于顶栏，批量操作仍在顶部固定区进行。进入批量管理时分类选择默认展开，展开后独立滚动，高度不超过窗口的 24% 或 200px；视频区始终可以点击或框选。收起不丢失勾选。分类项较多（含一级共 9 项以上）的卡片在宽窗口中跨两列加宽，卡片内部将每个二级分类与它的全部三级分类作为完整分组，按两列的剩余空间排列，不拆散同一分支；窄窗口退回单列。进入和退出批量管理只更新操作面板及勾选标记，保留视频卡片与侧栏节点。

“小工具”集中放置 B 站网页辅助功能。“显示评论 IP 属地”默认关闭，切换后自动保存。

操作反馈复用现有粒子波场磨砂面板，在右上角、顶栏下方 12px 自动弹出；位置随顶栏高度、批量区展开及窗口尺寸调整。打开弹窗时，通知留在顶栏下方，并显示在弹窗和模糊遮罩上方。普通提示 5 秒后消失，失败提示 8 秒后消失；新消息重新计时，完整记录保存在本机操作日志。弹窗支持关闭按钮和 Escape，键盘焦点限制在弹窗内，关闭后回到入口。

## 5. 分类目录与视频分类的固定边界

### 分类目录

分类目录表示“有哪些分类，以及它们之间的层级关系”。统一使用以下表达：

- 编辑分类目录
- 让 AI 生成分类目录
- 导入并替换分类目录
- 恢复默认分类目录

避免使用含义不明确的“更新分类列表”。相关说明应明确写出：

> 分类目录决定可以使用哪些分类；生成目录本身不是在给每个视频分类。

“编辑分类目录”分为“手动编辑”和“让 AI 生成目录”两个子页。使用宽幅面板和紧凑顶部导航，将主要空间留给目录。每个一级分类及全部子分类组成独立卡片，按卡片高度填充所有可用列，不使用会留下空列的 CSS 文字分栏。每个分类只占一行，约 28px 高，以字体深浅、粗细和缩进区分等级，完整层级放在名称提示中；去掉逐项层级徽章和拖动说明条。名称直接输入修改；拖动手柄到分类行上半部或下半部及周围间隙，分别放到该项前面或后面；只有一级、二级分类行的中部接收子分类并放到最后。三级分类整行用于前后排序，不接收子分类。插入位置用细线提示，切换判定保留小幅缓冲，指针经过输入框时不清除提示；输入框不超出行宽，拖动提示不改变行尺寸，拖到“上一级”提升一个层级，拖到“＋ 一级分类”独立成卡片。目录最多三级；子树一起移动，目标上级按整组深度自动选择，避免新增第四级。旧目录中更深的分类在草稿内提升到三级，保留分类 ID 和视频归属，确定保存后生效。禁止拖入自己或自己的后代。拖动开始时缓存可用目标，经过分类时只切换前后目标的高亮，不重复遍历目录。行尾小箭头保留上级选择器，作为键盘操作入口。分类顺序随草稿保存。保存和放弃修改固定在底部；新增、改名、移动和删除仍需点击“确定保存”才生效。完成名称输入时只刷新相关标签，不重建面板，避免点击保存丢失。AI 生成与替换目录在独立子页显示。

“AI 批量视频分类”分为“使用 API 自动分类”“手动复制 Prompt”和“自动触发”。API 页提供处理数量、重新处理已有 AI 分类和启动操作。默认仅处理待精细分类视频，数量不足一批时自动带入可处理数量。“待精细分类”标题旁的“一键 AI 分类”与“同步并更新”共用淡绿色玻璃、36px 高度和 14px 圆角。和标题间隔 12px，按钮相对垂直中心下移 2px，以对齐文字的视觉位置。它用已保存的 API 处理全部待精细分类视频，运行时可查看进度和停止。手动页依次提示生成并复制 Prompt、交给 AI、粘贴并导入视频分类结果。

“AI 服务”分为“视频分类 API”“OpenAI-compatible”和“Jev”三个子页。服务连接各自测试和保存，切换时保留草稿。各表单区块间隔 16px，标签与控件间隔 8px。

设置输入框与选择器使用浅中性色和细边框。设置、手动分类、批量管理和确认面板的操作按钮使用统一的无投影实色：普通操作为浅蓝灰，主要操作为较深的蓝灰，危险操作为淡红色。控件圆角为 12px，目录行保持紧凑。桌面表单使用两列，窄屏改为一列；目录表格的层级列保持完整可读，不显示横向滚动条。键盘焦点保持可见。

**视频分类服务**可选择 OpenAI-compatible 或 Jev（TypeSafe），两者密钥独立保存。Jev 从现有目录中为每个视频选择一个类别，不生成分类目录；分类目录生成始终使用 OpenAI-compatible 配置。Jev 结果仍显示“AI 分类”，结果不确定时留在“待精细分类”。

“视频分类使用的 API”选择器只保存视频分类所用的服务，适用于手动启动和自动触发。OpenAI-compatible 的温度和 JSON 输出选项收起在“高级选项”中。

**自动触发** 放在“AI 批量视频分类”下，可选择关闭、每天、每周，或在“待精细分类”达到用户指定数量时运行。数量阈值只在数量模式下显示。自动流程保留手动确认。

**操作日志** 有独立的设置入口，自动保存最近 200 条页面操作反馈，显示时间、状态和内容，最新记录在上方。记录仅保存在本机，刷新后保留；连续相同反馈不重复记录。日志不保存已配置的 API 密钥，存储失败时明确提示当前记录未持久化。

## 6. 视频卡片操作

封面优先使用 B站提供的清晰缩略图，首次成功同步后连续补存现有视频的封面文件，优先处理当前屏幕。后续新增和更换的封面分批保存。缩略图不存在或格式不支持时尝试原图；遇到网络或接口错误先暂停。占位区保持 16:9，并按状态显示“等待保存封面”“封面尚未保存”“封面暂不可用”或“暂无封面”。搜索、分类切换、排序与乱序尽量保留已加载的封面；后台同步未改变显示内容时不重建页面。预加载和复用不得改变滚动位置、输入法组词、批量勾选或手动分类结果。

视频区采用参考图中的浅灰背景（`#EEEEEE`）与白色圆角卡片，通过卡片间距和文字区留白区分内容。视频卡片不显示外边框或选中描边；选中通过柔和灰蓝渐变底色区分，批量选中另有勾选标记。封面铺满卡片顶部和左右边缘，顶部两角与卡片的 24px 圆角对齐，封面底部不设圆角；文字与操作区域保留内边距。底部操作采用浅灰底色、无边框按钮。键盘操作入口保留清晰的焦点提示。

顶部“乱序”按钮将当前筛选下的视频随机排列，通过卡片交叉移动与逐张错开呈现重排，不改变选择、分类或 B站服务端顺序。至少两个视频时可用，每次点击都会改变当前顺序；本次页面内保持随机顺序，详情刷新不重新洗牌，新同步的视频排在现有随机序列之后。排序选择器显示“随机排序”，选择其他排序即可退出；乱序生效后入口变为左右两半按钮：左侧循环箭头图标“刷新乱序”、右侧叉号图标“退出乱序”，两者保留悬停提示和可访问名称，视频少于两个时仍可退出。“浏览设置”提供默认打开的分类、默认视频筛选、默认排序方法、打开时随机排序和每批加载视频数，修改后自动保存。默认分类可选全部视频、待精细分类或目录中的分类。下级分类显示完整路径，已删除或不可用的默认分类回到全部视频。默认视频筛选排在排序前面，使用顶栏的时长和部分播放选项。默认分类、筛选与乱序从下次打开页面开始生效，退出乱序时恢复默认排序。顶栏临时筛选和排序只影响本次浏览。每批默认加载 200 个视频，可设置为 1–1000 个。滚到列表末尾或点击“加载更多视频”可接着加载，修改批量大小时保留已显示的视频。系统开启“减少动态效果”时直接切换位置。

进入页面默认不选择视频；同步和详情刷新也不得自动选择第一条。仅保留用户主动选择且仍在稍后再看中的视频；所选视频被移除时清空选择，不自动切换到下一条。右下角“回到上一次打开的视频位置”始终可点击。需要时清除筛选并定位，提示已定位、已在当前位置、暂无记录、列表未加载、正在确认移出、视频已移出或无法定位。同步新增或重新加入的视频使用淡入上移动画，已有卡片平滑让位；详情刷新沿用当前动画进度，不从头重复播放。

顶部按钮取色以用户提供的参考图片为准：主页粉色 `#FF6699`，稍后再看蓝色 `#00AEEC`；同步配套绿色 `#39BD88`，动态配套黄色 `#FFCC55`，同步使用淡绿色玻璃与深绿色图标，三个站外入口仅在图标轮廓中保留对应色相（黄色适度加深以保证对比度），底色与阴影保持中性。

视频卡片采用以下交互：

- 删除“普通打开”文字按钮；
- 点击视频封面，直接打开普通 B站视频页面；
- “稍后播放”改名为 **稍后合集中打开**，用于进入 B站稍后再看播放上下文；
- “移出稍后”改为单独的删除图标按钮；
- 删除图标必须具有明确的 `title` 和 `aria-label`，推荐使用“移出稍后再看”；
- 点击删除图标后立即从当前列表隐藏，再由后台向 B站确认；确认失败时必须恢复视频并明确提示原因；
- 视频标题是否同时打开普通视频页可在实施时根据可访问性决定，但不得与卡片选择、文字选择或手动分类操作冲突。

实现时继续遵守已有交互约束：不得引入滚动跳动、文本选择丢失、输入法异常或批量选择失效。

删除后其余视频卡片平滑补位，失败恢复时也使用位置过渡；系统开启“减少动态效果”时直接更新位置。手动调整视频分类与批量管理共用分组分类卡片：每个一级分类及其全部子分类放在一个独立卡片内，卡片填满所有可用列并按高度紧凑排列；分类项约 28px 高，每个分类都有独立复选框，勾选一级不会自动勾选子分类。通过字号、缩进和颜色区分等级，完整路径在悬停提示中显示；选中底色与复选框清楚呈现归属，不单独限制分类列表高度。手动调整点击“保存为手动确认”后才保存；视频封面在信息区内居中；底部三个操作按钮放在滚动内容区外的独立 16px 圆角区域，始终可见。底部面板与视频信息区采用一致的浅色半透明底色，按钮使用协调的蓝灰色，主要保存操作略深，保留键盘焦点。批量管理可同时勾选多个分类，一次追加到所选视频并保留原有分类；面板使用中性半透明底色，按钮与其他面板统一，保留键盘焦点。

手动分类面板打开时，用 320ms 移动整张视频卡片，保留白色背景、封面、标题、分类徽章、辅助信息和按钮。卡片按封面的宽度等比例放大或缩小，以封面在卡片内的偏移为基准，让封面位置与尺寸准确对齐面板中的封面。前 160ms 面板与背景遮罩保持透明，背景不模糊；移动的后半段就开始用 280ms 从卡片目标范围向外展开面板，整体在 440ms 完成。展开期间仅显示移动卡片中的封面，移动到位后封面保持固定，原卡片文字区先退出，面板中的完整标题与视频摘要随后显现，背景遮罩和模糊同步渐入。原卡片整体保留空位，关闭面板后才恢复，避免重复卡片与动画结束时闪回；选中底色在关闭面板后更新。当前分类徽章位于标题下方，保留卡片中的来源颜色与分类配色；封面保持 16:9，桌面宽度 280px，使用完整 16px 圆角，标题采用 20px 字号和 1.4 行高。减少动态效果时直接显示面板；关闭、重绘、滚动或调整窗口尺寸时立即结束过渡，面板内容恢复可见。

点击设置按钮时，磨砂弹窗从按钮的实际位置与大小开始，用 420ms 移动并扩展到完整面板；标题与内容在 120ms 后开始渐入，背景遮罩在 80ms 后开始渐入。切换设置子页不重新播放打开动画。关闭、重绘或调整窗口尺寸时结束动画，保留草稿与滚动位置；减少动态效果时直接显示完整面板。目录卡片排列使用未缩放的尺寸，避免打开动画影响布局。

## 10. 圆角层级

顶栏生效渐变采用较低饱和度（58% 至 60%）和较高明度（84% 至 87%），不叠加整块乳白遮层；生效控件去掉白色描边、内侧白色高光与玻璃边缘伪元素，键盘焦点提示保留。颜色由同一片静态渐变连续覆盖按钮内外，由五片大小、位置和浓度不同的径向柔散色雾自然交融，不使用波浪形状或固定外轮廓；绘制区域上下扩展 10px，左右扩展 12px，使用 5px 的轻微模糊与四边透明过渡，让颜色在到达绘制边界之前缓慢消散，局部轻微溢出，不把内部渐变与外部光斑分开绘制。

参考 Apple 的同心圆角原则（https://developer.apple.com/documentation/swiftui/edge/corner/style/concentric），按容器、卡片、控件和内部小元素分配圆角，而不是全部使用同一数值。以下数值为本页面的设计选择：左侧栏、设置弹窗与中间滚动区使用 24px，磨砂顶栏使用 24px；视频卡片使用 24px、通知消息使用 16px；顶栏控件使用 14px，其余输入框、下拉框、普通按钮与分类玻璃使用 12px；视频卡片内部按钮使用 14px、小徽章使用 8px。顶栏内边距为 10px，与内部 14px 控件圆角形成 24px 的同心外圆角，控件高度保持 36px；工具栏仍保留 14px 光效绘制空间，用负外边距抵消额外占高。侧栏分类行到外框的横向距离含边框共 12px，分类玻璃为 12px 圆角；行内左侧为 12px、右侧为 16px（相对左侧增加 4px），补偿二三级分类缩进带来的视觉偏重，4px 选中圆点放在左侧留白内，不为未选中项额外缩进。视频正文与底部按钮距卡片边缘 10px，按钮底边与对应左边或右边距卡片外框均为 10px，配合 24px 卡片与 14px 按钮圆角，底部外侧圆弧中心对应；展开下拉列表使用 18px，配合 6px 内边距和 12px 选项圆角。视频封面贴边，因此顶部圆角与卡片共用 24px，底部保持直角。分类和通知的玻璃层继承容器圆角；粒子、状态小圆点和滚动条仍保持圆形或全圆角。所有尺度由 CSS 变量统一维护。

分类、视频状态筛选、搜索、乱序和全部常规排序统一为卡片交叉移动与逐张错开：已有卡片从当前显示位置移动，距离超过视频区宽或高的 60%、原位置在屏幕外或新出现的卡片，从新位置最近的视频区边缘滑入，不使用淡入；移动为 420ms，所有可见卡片逐张错开，间隔最多 24ms、累计错开最多 168ms，卡片较多时缩短间隔。离开的可见卡片向最近边缘退场并淡出；空结果小幅上移出现。连续操作重新捕获当前显示位置，详情刷新沿用动画进度，保持滚动位置。搜索与分类同时生效；搜索词实际生效、时长或部分播放筛选生效以及乱序生效时，对应控件使用贴在通透玻璃上的静态渐变，不使用分类光流和波场；搜索采用薄荷冰蓝、时长采用蜜桃香槟、乱序采用浅紫玫瑰，渐变覆盖控件，上下边缘以不同位置和大小的柔和色斑轻微不对称溢出，不形成完整光圈；保留原有流动粒子，粒子层在控件四边扩展 8px，允许上下轻微飘出；工具栏滚动区域留足 14px 的上下绘制空间，避免裁切渐变与粒子，保持按钮位置和顶栏高度；文字和图标保持清晰；清空搜索、取消时长或部分播放条件或退出乱序时撤去光效。输入法组词期间沿用当前已生效的筛选状态，减少动态效果时停止粒子运动并保留静态渐变，强制颜色时隐藏光效。搜索框不显示高亮外圈；当前分类标题旁显示中性灰底的“关键词筛选中”，数量旁提示“仅显示搜索匹配”。输入法组词期间不更新结果，结束输入后以 100ms 合并输入更新。减少动态效果时直接显示结果。
